직원 확인정보도 Excel에서 일괄 반영할 수 있습니다. Add only these four columns to the right side of the original TripCoupon admin Excel: Check Status / Last Checked / Checked By / Check Notes (Optional). For verified partners, enter Confirmed in Check Status. 이 4개 열은 제휴사 정보 변경 비교에서는 제외되며, Apply Changes 시 확인기록만 별도로 저장됩니다.

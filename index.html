Upload TripCoupon Admin File

Upload the .xlsx file downloaded from TripCoupon Admin without modifying the original data. CSV is also supported.

Staff verification data can also be applied in bulk from Excel. Add only these four columns to the right side of the original TripCoupon admin Excel: Check Status / Last Checked / Checked By / Check Notes (Optional). For verified partners, select Checked in Check Status. Use Checked / Not Checked, set Last Checked as YYYY/MM/DD, and select Teddy / Kate / Others in Checked By. These four columns are excluded from partner-data change comparison. When you click Apply Changes, only the verification records are saved separately.

After upload, if the New / Discontinued / Changed counts differ significantly from what you expect, do not click Apply Changes.
